# Education Platform Android App (System Project)

An advanced, feature-rich Education Platform built for Android using Java. This application provides a comprehensive learning experience for users, featuring video courses, interactive quizzes, an AI-powered chatbot, and a robust admin panel for content management. 

## 🚀 Features

### For Users
* **User Authentication:** Secure sign-up and login via Firebase Authentication.
* **Browse & Search Courses:** Explore a catalog of educational content, view course details, and search for specific topics.
* **Video Learning:** Built-in video player for consuming course materials seamlessly.
* **Interactive Exams & Quizzes:** Test your knowledge with a dedicated exam section.
* **AI Chatbot:** Integrated Google Gemini AI to assist users, answer questions, and provide smart recommendations.
* **User Profiles:** Manage personal details and track progress.

### For Administrators
* **Admin Dashboard:** A dedicated interface to oversee the platform.
* **Course Management:** Add, edit, and delete courses.
* **Admin Chat:** Communication tools for administrative purposes.

## 🛠️ Technology Stack

* **Android UI & Framework:** Android SDK (API 34), Java, Material Design Components, ViewBinding, Navigation Component.
* **Architecture:** MVVM (Model-View-ViewModel), Repository Pattern, LiveData for UI state management.
* **Backend:** Firebase (Firestore Database, Realtime Database, Storage).
* **Networking & APIs:** OkHttp, Gson for JSON parsing.
* **AI Integration:** Google Gemini AI API.
* **Media & Animations:** Lottie Animations, Glide for image loading.

## 🏗️ Getting Started

1. Clone this repository.
2. Open the project in **Android Studio**.
3. Ensure you have the `google-services.json` file added to your `app/` directory for Firebase configuration.
4. Sync the Gradle files.
5. Build and run the app on an Android emulator or a physical device.
